# Munasabat - Landing Page (منظومة مناسبات)

صفحة الهبوط الرسمية لمنظومة إدارة المناسبات وبوابات الدخول عبر QR (**منظومة مناسبات - Munasabat**).

## 🚀 المميزات
- واجهة SaaS حديثة وثنائية اللغة (العربية / English) بدعم RTL متكامل.
- روابط تحميل مباشرة لتطبيق الويندوز المكتبي وتطبيق الأندرويد للماسحات.
- استعراض لوحة التحكم الفعلية للنظام ومعاينة بطاقات الدعوة المطبوعة.
- متجاوبة بالكامل مع مختلف أحجام الشاشات والأجهزة المحمولة.

## 💻 التشغيل محلياً
```bash
npm run dev
# أو
python -m http.server 8080
```
